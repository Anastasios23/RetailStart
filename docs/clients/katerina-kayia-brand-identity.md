# Brand identity research — Φαρμακείο Κατερίνα Καγιά / Katerina Kayia Pharmacy

Research date: 2026-10-27  
Scope: public **primary** sources only (owned social/commerce/listing pages and official pharmacy registries). Not an owner brief.

---

## 1. Visual identity

### Logo (canonical mark)

The pharmacy’s recurring mark is a **white, interwoven “pill-loop” cross** on a **solid green square/circle** background. The cross is built from four rounded, capsule-like strokes that meet at the center—not a flat block Greek/EU green cross.

- **Facebook profile image** shows the mark on a green field: [https://www.facebook.com/katerinakayiapharmacy/](https://www.facebook.com/katerinakayiapharmacy/)
- **Instagram profile photo** matches the same green field + white looped cross: [https://www.instagram.com/katerinakayiapharmacy/](https://www.instagram.com/katerinakayiapharmacy/)
- **Instagram grid creative** also uses a **wordmark lockup**: stacked caps **KATERINA / KAYIA / PHARMACY** beside an outline version of the looped cross (dark grey on white): [https://www.instagram.com/katerinakayiapharmacy/](https://www.instagram.com/katerinakayiapharmacy/)

### Secondary / directory artwork (farmakeia.com.cy)

The verified [farmakeia.com.cy](https://farmakeia.com.cy/1207/farmakeio-katerina-kayia) social preview uses a **map-themed banner** (not the social avatar):

- **ΦΑΡΜΑΚΕΙΟ** in teal, high-contrast **serif caps**
- **ΚΑΤΕΡΙΝΑ ΚΑΓΙΑ** in **bold sans caps**, dark navy
- Icon: **green pharmacy cross merged with a red map pin** (location cue), repeated as map markers  
  Source image: [https://farmakeia.com.cy/storage/social_images/NLDdc_398.png](https://farmakeia.com.cy/storage/social_images/NLDdc_398.png)

Treat this as **directory creative**, not the primary social logo, but useful for typography and “find us on the map” messaging.

### Typography cues

- **Social wordmark:** wide-tracked **sans-serif all caps** for “KATERINA KAYIA PHARMACY” — [https://www.instagram.com/katerinakayiapharmacy/](https://www.instagram.com/katerinakayiapharmacy/)
- **Directory banner:** **serif caps** for “ΦΑΡΜΑΚΕΙΟ” + **heavy sans caps** for the owner name — [https://farmakeia.com.cy/storage/social_images/NLDdc_398.png](https://farmakeia.com.cy/storage/social_images/NLDdc_398.png)
- **Post graphics:** bold Greek display type for promos and duty notices (e.g. “ΕΦΗΜΕΡΙΑ”, “25% OFF”) — [https://www.instagram.com/katerinakayiapharmacy/](https://www.instagram.com/katerinakayiapharmacy/)

For the demo site: pair a **clean Greek-friendly sans** (UI, product names) with optional **serif for “Φαρμακείο”** in hero or footer only, echoing the directory banner without copying it literally.

### Green cross usage

- **Primary brand:** stylized **looped white cross** on **green** — not a standalone EU green cross icon — [https://www.facebook.com/katerinakayiapharmacy/](https://www.facebook.com/katerinakayiapharmacy/)
- **Directory variant:** conventional **green cross + red pin** for “we are on the map” — [https://farmakeia.com.cy/1207/farmakeio-katerina-kayia](https://farmakeia.com.cy/1207/farmakeio-katerina-kayia)

Avoid replacing the looped mark with a generic pharmacy cross in the demo UI; use **brand green** for accents, chips, and CTAs instead.

### Wolt venue photography

Hero image is a **bright flat-lay** of dermo/OTC brands (Apivita, La Roche-Posay, Vichy, The Ordinary, etc.) on **warm cream**, signaling premium **self-care and dermocosmetics**, not clinical Rx dispensing — [https://wolt.com/en/cyp/nicosia/venue/katerina-kayia-pharmacy](https://wolt.com/en/cyp/nicosia/venue/katerina-kayia-pharmacy).

## 5. Design implications — owned site (Wolt-*like*, not Wolt-branded)

### Layout patterns to echo (without copying Wolt UI or trademarks)

| Pattern | Brand-aligned implementation |
| --- | --- |
| **Horizontal category chips** | Scrollable pills: brands (Korres, The Ordinary, …) + need states (Συμπληρώματα, Μαλλιά, Κρυολόγημα) mirroring Wolt taxonomy — [Wolt venue](https://wolt.com/en/cyp/nicosia/venue/katerina-kayia-pharmacy). Use **brand green** (`#1EA87E`) for active chip, **cream** (`#F0E4D2`) or white for surfaces. |
| **Product cards** | Photo-forward cards, price prominent, “+” add action; reuse **cream studio** aesthetic from Wolt hero — [Wolt venue](https://wolt.com/en/cyp/nicosia/venue/katerina-kayia-pharmacy). |
| **Rails** | Sections **Δημοφιλή** / **Νέα** / **Δερμοκαλλυντικά** analogous to “Most ordered” / “New” — [Wolt venue](https://wolt.com/en/cyp/nicosia/venue/katerina-kayia-pharmacy). |
| **Delivery messaging** | Hero: Greek line from Instagram bio themes + subline inspired by **wellness + delivery**, not “Wellness, delivered!” verbatim — [Instagram](https://www.instagram.com/katerinakayiapharmacy/), [Wolt](https://wolt.com/en/cyp/nicosia/venue/katerina-kayia-pharmacy). Link out to **their** Wolt venue as one channel among phone / visit. |
| **Trust / Rx boundary** | Footer or banner: **συνταγές στο φαρμακείο**, **εφημερία — καλέστε πρώτα**, mirroring duty post style — [Instagram](https://www.instagram.com/katerinakayiapharmacy/), [cynightmeds.com](https://cynightmeds.com/el/pharmacy/1207). |
| **Location** | Map link + landmark copy from registries; optional subtle **pin accent** `#E02810` on map CTA only — [farmakeia.com.cy](https://farmakeia.com.cy/1207/farmakeio-katerina-kayia). |
| **Logo in header** | Prefer **looped cross on green** or outline version from Instagram lockup — [Instagram](https://www.instagram.com/katerinakayiapharmacy/). Do **not** use Wolt logo or Wolt cyan. |
| **Typography** | UI sans with Greek support; navy `#082870` body/headings, green for primary buttons. |

### Do not

- Use Wolt brand colors, logo, or tagline **“Wellness, delivered!”** as owned-site H1.
- Present the shop as an **online prescription pharmacy**.
- Imply **Google review scores** without a verified Google Business source.
