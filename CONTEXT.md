# Project Context

## Project

`retail-starter` is a reusable Retail E-commerce Starter that can later be adapted for multiple client businesses.

## Initial target

Normal retail businesses selling physical products.

## Current phase

Documentation and scope organization before implementation. Application dependencies and runtime configuration have not been selected or installed.

## Deployment model

Each client should initially have an isolated deployment. The project is not currently planned as a multi-tenant SaaS architecture.

## Proposed technology direction

- Next.js and TypeScript for the storefront
- Medusa for the commerce backend
- PostgreSQL
- Stripe
- Cloudflare where appropriate for frontend, CDN, or DNS needs

This is a proposed direction, not an implementation decision record.

## Open context

Client-specific requirements, exact platform versions, deployment details, and other implementation decisions are `TBD`.
