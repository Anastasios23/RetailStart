# retail-starter

Reusable Retail E-commerce Starter for client businesses selling physical products.

## Current status

This project is in the documentation phase. No application code, dependencies, or implementation configuration has been created.

## Proposed technology direction

The current direction is Next.js and TypeScript for the storefront, Medusa for the commerce backend, PostgreSQL, Stripe, and Cloudflare where appropriate for frontend, CDN, or DNS needs. This direction is not yet implementation configuration.
